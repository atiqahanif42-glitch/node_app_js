Node.js User Filtering Script

This repository contains a Node.js script created for **Task 2**.

What it does:
- Fetches user data from https://jsonplaceholder.typicode.com/users
- Filters users whose company catchPhrase includes "group" or "service"
- Transforms data using Object Destructuring into format:
  User: [Name] | Email: [Email] | City: [City]
 How to run:
```bash
node app.js
